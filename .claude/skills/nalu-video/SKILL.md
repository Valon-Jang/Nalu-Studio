# Nalu 영상 제작 규칙

목표 스타일 = 신비한건축사전 문법 (CEO 지정 기준, 6편 165숏 분석 2026-08-06).
경계: **문법·통계만 추출한 것. 해당 채널의 영상·에셋·자막 문구 재사용 절대 금지. 모든 소재는 자체 모델링/생성.**

## 규격

- 1080x1920 세로, 24fps, 최종 믹스 −14 LUFS
- 색: 저채도 회색 기조 (#404040~#a0a0a0 밴드) + 소재 고유색(흙 #806040, 초목 #606040, 물 청록 #608080). **포인트는 연보라(주석 — Nalu 채널 색, CEO 지정)와 파랑(물·얼음) 딱 둘.** 레퍼런스 채널은 빨강을 쓰지만 우리는 **연보라로 차별화** — 빨강 주석 금지. 화면이 원색으로 시끄러우면 실패
  - 주석 기본: `#A987E8` / 발광·강조: `#C9B3F2` / 라벨 필 박스: `#6F4DB8`+흰 텍스트 (어두운 재질 위 가독 확보)
- 내레이션이 먼저다: 숏 경계는 내레이션 구절(luna-narration 스킬의 timeline)과 1:1 동기

## 페이싱 (측정값)

- 숏 길이: 중앙값 2.3초, IQR 1.5~4.9초. **8초 초과 숏은 편당 최대 2개** (165숏 중 2개뿐이었음)
- 편당 19~45숏 / 80~95초
- 훅: 첫 1~3숏은 리얼월드 와이드/매크로 + 즉시 주제 타이틀 (예: 도로 위 구멍 + [포트홀] 브래킷 타이틀). 시청자가 아는 현재 풍경에서 시작해 즉시 낯선 사실 제시

## 월드 3종 — 모든 숏은 셋 중 하나

**A. 리얼 월드** (훅·전환·마무리용, 편당 ~30%)
- 포토리얼 환경: 도로·지형·건축·도시. PBR 재질 승부 (아스팔트 골재, 이끼 낀 석재, 수면)
- 카메라: 숏당 무브 1개 — 슬로우 푸시인 / 에어리얼 오빗 / 탑다운 / 로우 트래킹. 본론은 차분하게, 단 **훅·오프닝은 큰 움직임으로 시작** (CEO: "건축사전은 처음에 큰 움직임" — 정적 푸시인으로 열지 말 것)
- **빛·에너지 연출 원칙** (CEO 2026-08-07): 데이터·신호·에너지는 띠/밴드가 아니라 **실제 광원이 번쩍하며 질주하는 광점**으로 — 지나갈 때 주변이 순간 밝아져야 하고, 카메라가 그 빛을 **추적(체이스)**하면 생동감. 컴포지터 글레어로 번쩍임 보강

**B. 컷어웨이 월드** (메커니즘 설명의 주력, ~40%)
- 시그니처: **지층/구조 단면**. 도로·성벽·무덤을 칼로 자른 듯 열고, 위 세계는 그대로 (단면 위로 차가 달림)
- 리얼 재질 유지 + 배경만 밝은 회색 무한 스튜디오로 뽑아내는 디오라마형도 병용 (연못 축조 단계, 성벽 내부 구성)
- 매크로 접사: 골재 사이 물 스밈, 얼음 결정 성장, 돌 틈 나무뿌리 — 파랑 반투명 셰이더 + 절차적 애니

**C. 스튜디오 실험실** (원리 증명·비교, ~30%)
- 밝은 회색 무한 배경(때로 그리드 바닥) 위 미니 디오라마/물리 실험: 흙더미에 비 내리기, 블록 붕괴, 물 붓기, 욕조 은유 같은 오브젝트-온-화이트
- 비교 프레임: 좌우 분할(일반 vs 배수성) 또는 O/X
- 저폴리 양식화 허용 구역: 역사 와이드(채석장, 운반 행렬)는 저폴리 지형+콩알 인부로 물량감 표현 — 리얼과 섞여도 회색 기조면 안 붙음 없이 어울림

## 시그니처 오버레이 시스템 (없으면 이 채널 느낌이 안 남)

- **연보라 주석 세트** (`#A987E8`, 발광 `#C9B3F2`): 치수선+수치(94m, 179cm), 브래킷 박스, 굵은 화살표(힘·압력 방향), X 표시, 타깃 서클, 지도 위 경로 점선, 감시 콘 라이트, **와이어프레임 투시**(지하 구조를 연보라 발광 와이어로), **이음새 발광**(구조 틈을 따라 연보라 에미션)
- **흰 스트림라인 + 연보라 소용돌이**: 유체 흐름 시각화 (CFD 느낌). 물 흐름·바람 설명의 기본기
- **파티클 데이터 비주얼**: 인구=구슬 무더기, 개수=+숫자 필드, 수량=연보라 점 군집 — 숫자를 3D 공간의 물량으로 번역
- **키워드 타이포 카드**: 핵심 단어(얼음, 타원형, 천 년)를 화면 중앙 대형 흰/연보라 타이포로. 장 전환 겸용. 3D 입체 타이틀(브래킷 [포트홀])은 훅 전용
- 라벨: 빨간 필 박스 + 흰 텍스트 (제설제, 빈 공간, 내부 구성), 말풍선형도 가끔
- 우하단 ✦ 스파클 워터마크 자리엔 우리 브랜드 요소 사용 (건축사전 것 모방 금지)
- 자막: 기존 규칙 유지 — 하단 중앙 흰 볼드, Noto Sans KR, MarginV 540, 내레이션 구절과 동기

## 스토리 아크 (6편 공통 패턴)

1. **현재 리얼월드 훅** (1~3숏): 아는 풍경 + 놀라운 사실 제시
2. **문제/질문 제시**: 연보라 주석으로 스케일·수치 각인 (50만 개, 18.6km)
3. **메커니즘 루프** (본론, B·C월드 교대): 원인→과정→결과를 컷어웨이와 실험으로 반복. 한 루프 = 내레이션 한 문장군
4. **해법/원리 정리**: 키워드 카드 + 비교 프레임
5. **리얼월드 복귀 + 여운 한 줄** → 브랜드 아웃트로 (Nalu 엔드카드)

## 제작 순서 (CEO 질문의 답 — 이 순서대로)

1. **내레이션 확정 먼저** (luna-narration 스킬) → `_report.json` timeline이 숏리스트의 뼈대
2. **숏리스트 작성**: 구절마다 {월드타입 A/B/C, 씬 내용, 카메라 무브 1개, 오버레이} 지정. 위 페이싱 통계 준수
3. **베이스 3D 월드부터 구축**: 편당 핵심 환경 1~2개(도로, 지형+구조물)를 먼저 만들고, **컷어웨이·디오라마는 그 에셋을 잘라서 파생** (새로 만들지 않음 — 재사용이 일관성의 비결)
4. **카메라 패스 설계**: 배경 월드 안에서 카메라가 이동하며 여러 숏을 뽑는 방식 (씬 하나 = 숏 여러 개). 숏당 무브 1개 원칙
5. **렌더**: Blender EEVEE (SPIDER 검증 파이프: `scripts/spider_blender_lib.py` 계열, ~1.5초/프레임 1080x1920 샘플24, 짝수 프레임 렌더→홀드로 슬로우 무브 24fps. Blender 5.2 종료 시 무해한 EXCEPTION_ACCESS_VIOLATION — png 존재로 성공 판정). 데이터 씬(그래프·카운터)은 PIL 모그래(`spider_visual_engine.py` 계열)
6. **오버레이 패스**: 연보라 주석·타이포는 렌더 위 2D 합성(PIL) 기본, 투시 와이어·이음새 발광·콘 라이트만 3D에서
7. **조립**: 내레이션 타임라인에 컷 스냅 → 자막(ASS, Name 필드 필수, WrapStyle 0, 폰트 `_fonts/`) → 절차적 SFX 베드(ORIGINAL_PROCEDURAL_ONLY) → 브랜드 아웃트로 부착 → 먹싱
8. QC: 컷·자막·내레이션 싱크 확인, 팔레트 이탈 숏 점검

## 품질 바 (판정 기준)

- 재질이 승부처: 아스팔트 골재 알갱이, 석재 이끼·풍화, 수면 반사가 "만질 수 있을 것 같은" 수준이어야 함. 저폴리는 C월드 역사씬만
- 조명: 부드러운 주광 + 옅은 안개(원경 뿌옇게). 스튜디오는 균일 소프트박스 느낌
- 렌더 예산이 부족하면 **숏 수를 줄이지 말고 카메라 무브를 단순화**할 것 (이 채널의 밀도는 컷 수에서 나옴)
