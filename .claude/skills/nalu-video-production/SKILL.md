# Nalu 영상 제작 규칙 (Blender 구현)

기획은 `nalu-video` 스킬(월드 3종·숏리스트·페이싱). 여기는 **만드는 법**.
2026-08-06 구현 가능성 검증(T1 4라운드·T2·T3)에서 확정된 노하우.

## 환경

- Blender 5.2: `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`
- 헤드리스: `blender -b --python scene.py -- --out X.png --samples 64`
- **종료코드 신뢰 금지** — 렌더 후 크래시(코드 11 등) 빈발. **PNG 존재로 성공 판정**
- 정지 1080x1920 s64 ≈ 90초/장 (CPU). 반복 부담 없음 — 많이 돌려라
- 엔진 감지: `'BLENDER_EEVEE' if in enum else 'BLENDER_EEVEE_NEXT'`. Filmic + Medium/High Contrast
- 월드 씬 스크립트: `scripts/visual_worlds/` (t1 바다단면 / t2 섬유 / t3 저폴리지도가 시작점)
- **CC0 텍스처·HDRI(Poly Haven 등) 사용 CEO 승인됨** (2026-08-06) — 재질 밀도가 레퍼런스 대비 최대 격차이므로 근접 컷은 반드시 PBR 텍스처 사용. 절차적만으로는 "만질 수 있는" 밀도 안 나옴

## 검증된 씬 레시피

**바다 단면 (W1)** — t1_ocean_cutaway.py 4차 확정값:
- 구도: SEABED −5.5, 카메라 z −2.0 / lens 26 / pitch 83° → 수면선 상단 1/4 + 해저 동시
- 물: 볼륨 큐브 Principled Volume — color (0.02,0.10,0.18), density 0.16, anisotropy 0.35
- 신광 광선: 스포트 4개 **수면 바로 아래(z −0.15)** energy 15000 / 26° / blend 1.0 — 수면 위에 두면 볼륨에 안 걸림(1차 실패 원인)
- 케이블 펄스: 외피 다크 PBR에 **표면 믹스로 대시 에미션** (웨이브 UV scale 2.2 + 램프 0.965~0.985 + 에미션 시안 4.0). 코어를 외피 안에 넣으면 안 보임(2차 실패 원인)
- 해저: displace(CLOUDS 2.2, str 0.9) + 노이즈 범프 scale 14 + 색 변주 노이즈 믹스. **shade_smooth 필수** (안 하면 각짐)

**저폴리 역사 지도 (W3)** — t3 1차 성립. 남은 스타일 패스: 바다를 세피아 웜톤으로, 땅/바다 명도차 확대, 스탬프 확대+연보라 포인트, 비네트

**광섬유 매크로 (W2)** — 6라운드 미수렴, 세션 중단 상태 (`t2_fiber_macro_v2.py`, `t2_fiber_inside.py`). 적립 교훈:
- **EEVEE 투명 유리 튜브 매크로 = 구조적 우유관** (transmission 산란+겹층 알파+광역 림이 유백색 수렴). 외부 유리 구도 금지
- "섬유 내부" 구도가 유망하나 두 함정: ① 카메라 축상 배치 = 나선이 동심원 스피로그래프化 (오프축+틸트 필수) ② **스트림 발광 3~5 상한** — High Contrast Filmic에서 12는 전부 백화되어 색 소실
- 나선/코일 폴리라인 회전당 20점 이상 (미달=지그재그), 매크로 DOF f/4 이상, 터널 헤이즈 밀도 0.012 이하
- 다음 시도 방향: 내부 구도 유지 + 발광 3~4 + 채도 유지 확인 + 벽 반사 억제(metallic 0.2) + 모션 우선 판정 (정지보다 모션에서 판정하는 게 이 컷의 본질)

## 공통 함정 (재발 금지)

1. 에미션은 **전용 Emission 노드** — Principled의 Emission 입력은 버전따라 무시됨
2. 발광체를 불투명 메시 안에 넣지 말 것 — 표면 셰이더 믹스로
3. 볼륨 라이트는 광원이 볼륨 **안**에 있어야 함
4. 바위·소품의 z는 displacement 후 높이 기준으로 (원면 기준이면 뜨거나 묻힘)
5. 모든 유기 형태 shade_smooth
6. 에스컬레이션식 반복이 정답: 렌더 → 이미지 확인 → 원인 특정 → 패치 (라운드당 ~2분)
7. **가산 이펙트(코스틱 등)는 위치 마스크 필수** — 전면 가산하면 근경 텍스처가 우유빛으로 씻김 (T1 v5.1 퇴행 사례: 코스틱 mul 2.2→4.5가 근경 파괴. 중경 밴드에만 걸고 근경 보호)
8. **숏 프레임 수 공식**: `F_END = 구절길이 × 24` (step2 렌더 → 실프레임 = 길이×12, 12fps 재생 = 구절길이). 길이×12를 F_END에 넣으면 숏이 절반 길이가 되어 **후반부 정지 = 뚝뚝 끊김** (드래프트 v1/v2 사고). 조립 전 검증: 렌더 프레임수/12 ≈ 구절길이. 조립 시 minterpolate 12→24 보간으로 홀드 계단감 제거
9. **숏 재사용 시 이어재생·오프셋 필수**: 같은 숏을 여러 구절에 배정할 때 구절마다 처음부터 재생하면 "같은 장면 반복" 체감 (드래프트 v2 사고). 연속 구절은 이어재생, 떨어진 재사용은 시작 오프셋. 근본 해결은 폴백 최소화 — 숏 부족하면 렌더를 더 하지 재사용하지 말 것
10. **Blender 5.x API 변화 주의**: `Action.fcurves` 제거(이징 루프 쓰지 말 것 — 기본 베지어로 충분), `Scene.node_tree` 제거 → 컴포지터는 `bpy.data.node_groups.new(..., 'CompositorNodeTree')` + `sc.compositing_node_group` + `NodeGroupOutput` (글레어 등). 모션 v2 스크립트(`t1_motion_test2.py`)에 양쪽 호환 패턴 있음
11. T1 기준 버전: v5가 티어H 기반 확정본 (`scripts/visual_worlds/t1_ocean_cutaway_v5.py`는 v5.1 값이므로 코스틱 mul 4.5→2.2, vor 9→5.5 원복 후 사용)

## 조립 치명 함정 (v3까지의 '끊김' 사고 전체 원인 — 재발 시 즉시 여기 대조)

1. **[미해결·최우선] A/V 드리프트**: 조립기가 블록 간 0.5초 무음 구간에 갭 프레임(직전 숏 마지막 프레임 홀드)을 **블록 경계마다** 삽입해야 하는데, v3까지는 끝에만 몰아 넣어 영상이 오디오보다 점점 앞서감(끝에서 4초 차 + 말미 정지). `build_subsea_v3_assembly.py`의 프레임 루프에 블록 경계 갭 삽입을 추가할 것. **"여전히 끊긴다"의 1순위 원인.**
2. 숏 프레임 수: F_END = 구절길이×24 (step2 렌더). ×12를 넣으면 절반 길이→후반 정지 (v1 사고)
3. 같은 숏 재사용 금지·부득이하면 이어재생+오프셋 (v2 사고)
4. concat demuxer 금지 → filter_complex concat (길이 2배 사고)
5. 12fps 홀드+minterpolate는 미봉책 — **최종 화질은 step1 풀렌더(24fps 실프레임)**가 정답. 드래프트만 step2+보간
6. 체인 러너는 **반드시 단일 실행** — 재시작 전 `ps -ef | grep run_` 확인·kill (3중 실행으로 로그 오염+부분 프레임 스킵 사고). 스킵 판정은 숏별 기대 프레임 수 기준
7. 드래프트는 75%·s16으로 4배 가속, 조립 시 1080 업스케일. 최종만 100%·s64

## 품질 티어 기준 (CEO 확정 2026-08-06: "이 정도 수준 할 때는 이 정도는 해야 한다")

**최소 보장선 (CEO 합격 기준점, 2026-08-07 — "최소 이 정도 느낌과 퀄리티 보장. 이 스토리뿐만 아냐")**: 모든 주제·모든 영상의 히어로 컷은 **T1 모션 v2** (`scripts/visual_worlds/t1_motion_test2.py` + 블룸 후처리) 수준 이상이어야 한다. 그 수준의 정의:
- 주인공에 실제 지오메트리 디테일 (케이블=나선 외장+중계기급의 밀도를 각 주제의 주피사체로 번역)
- 근경 CC0 PBR + 깊이 볼륨 + 부유 입자 + 원경 소거
- **움직이는 카메라** (체이스/트래킹 — 히어로 컷에서 정적 푸시인 금지)
- **에너지·데이터·신호 = 실광원 동반 광점 질주 + 블룸 번쩍임** (흰 띠 금지)
- 조립 시 블룸 후처리 패스 (하이라이트 추출→블러→스크린 가산, 임계 215·블러 18 기준값)
이 기준 미달 히어로 컷은 CEO에게 보여주기 전에 반려하고 반복할 것.

**0순위 원칙 — 주인공 먼저** (CEO 2026-08-07: "배경만 신경쓰고 정작 중요한 건 대충 한 느낌"): 내레이션이 말하는 **주피사체가 컷의 디테일 1순위**다. 배경(모래·안개·광선)을 아무리 채워도 주인공이 민짜면 실패. 주피사체에 실제 지오메트리 디테일(케이블이면 나선 외장·중계기, 기계면 볼트·이음새)을 먼저 넣고 배경은 그 다음.

**티어 H (히어로/시그니처 컷)** — 훅·수미상관·핵심 설명 컷 (편당 3~5개). 아래 7개 **전부 필수**, 하나라도 빠지면 티어 H 미달:
1. **CC0 PBR 텍스처** 재질 (albedo+normal+rough+disp 풀셋) — 절차적 노이즈만 금지
2. **환경 상호작용 광** — 수중이면 코스틱(보로노이 가산 믹스), 실내면 바운스 라이트 등 "공간이 빛을 만진 흔적"
3. **환경 매질의 실체** — 수면·안개·먼지를 실제 기하/볼륨으로 (얇은 선·균일 볼륨 금지)
4. **미세 요소** — 부유 입자·파편 등 깊이 스케일 큐 (비용 거의 0, 생략 금지)
5. **깊이 그라데이션** — 볼륨 밀도/색을 좌표 매핑 (균일 밀도 금지)
6. **근경 집중·원경 소거** (CEO 관찰: "멀리 보이는 배경은 명확히 구현 안 하더라 — 가까운 것만 신경. 이게 기술") — 카메라 근경만 고밀도 텍스처·지오메트리, **원경은 의도적으로 헤이즈/안개/심도에 묻는다**. 원경을 열심히 만드는 것은 시간 낭비이자 시선 분산. 안개 농도는 "원경 실루엣만 남는" 수준
7. **마감 패스** — 그레이딩+비네트+미세 그레인+연보라 주석 (PIL 합성, 생략 시 "미완성 광택")

**티어 S (표준 컷)** — 나머지 B·C월드 컷: 1(텍스처)·5(깊이)·7(마감)만 필수, 2·3·4·6은 씬 성격 따라
**티어 L (저폴리 양식화 컷)** — W3류: 7(마감)만 필수 + 명도 대비·실루엣 명료성. 텍스처 대신 플랫 컬러가 정체성

운영 규칙: 숏리스트 작성 시 각 숏에 티어를 표기하고, 스타일 프레임 판정도 티어 기준으로. 티어 H를 늘리면 일정이 터지므로 편당 3~5개 상한 유지.

## 품질 판정

- 스타일 프레임을 레퍼런스 프레임과 **나란히 놓고** 판정 (건축사전 분석 시트: scratchpad 소멸 시 재다운로드)
- 목표는 "같은 문법의 우리 버전" — 동일수준 아닌 유사수준. 근접 포토리얼 매크로가 최난이도, 중경·컷어웨이·스튜디오·저폴리는 도달 확인됨
